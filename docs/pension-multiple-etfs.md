# 연금저축 여러 ETF 체결 등록

연금저축 → 여러 ETF 매수·매도 체결 등록 → 거래 자산 → `＋ 새 ETF 등록`을 선택합니다.
ETF 이름, 국내상장 종목코드, 자산 구분, 실제 체결일·수량·가격을 입력하고 확인 후 저장합니다.
실제 주문·이체·자동매매 기능이 아닙니다. 기록한 거래는 기존 GitHub 연금 파일에 함께 저장됩니다.
저장소의 공개/접근 범위가 적용되므로 비밀번호·계좌번호를 거래 메모에 넣지 마세요.

- 기존 국내 기준 ETF/S&P500 잔고와 거래내역, 시작 잔고, 임의 메타데이터를 유지합니다.
- 추가 종목은 `etf_positions` 사전에 `etf:<정규화 코드.KS/KQ>` 키로 별도 보관합니다. 읽기만 해서는 파일을 변환하거나 저장하지 않습니다.
- 같은 종목은 기존 거래 자산을 선택합니다. 수량 합산·이동평균 취득가 계산, 일부 매도 평균가 유지, 전량 매도 후 재매수와 이력 보존을 지원합니다.
- 신상품 이름·코드는 사용자가 입력합니다. 앱이 ETF 여부나 연금계좌 매수 가능 여부를 자동 인증하지 않습니다. 실제 증권사 체결내역과 확인하세요.
- 매수·매도 금액의 현금 반영은 명시적 선택입니다. 수수료·세금은 계산에 포함하지 않습니다.
- 동일 코드 중복 등록, 초과 매도, 미래일·역순 거래, 잘못된 수량·가격, 잔액 부족을 거부합니다. 새 상품을 매도부터 등록하지 않습니다.
- 저장 전 최신 파일 버전을 비교하고 원자적 저장을 사용합니다. 응답 유실 재시도는 동일 거래 ID로 중복 반영하지 않습니다.
- 잔고 보정은 별도 확인 버튼으로만 가능하며 체결내역과 보정 전후 기록을 보존합니다. 보유 중인 기준 ETF의 코드를 다른 상품으로 덮어쓸 수 없습니다.
- 모든 ETF를 평가합계에 한 번씩 포함합니다. 보유 ETF의 정상 시세가 하나라도 없으면 전체 평가·비중·배분은 보류하며 0원으로 취급하지 않습니다. 미보유 종목은 시세가 없어도 합계를 막지 않습니다.
- 10초 갱신은 가격 영역에만 적용합니다. 매수 입력 중 자동 저장은 하지 않습니다.
- 현재가 카드는 고정 기준 ETF가 아니라 저장된 보유수량이 0보다 큰 모든 ETF에서 생성합니다. 현재 포트폴리오 표도 같은 범위이며, 미보유 ETF 시세는 조회하지 않습니다. 전량 매도한 종목은 카드·현재 표에서만 빠지고 원장·체결내역·재매수 선택은 유지합니다.
- 기존 50:30:20 참고배분은 해외주식/국내주식/채권·현금성 자산군 합계에 적용합니다. 개별 ETF의 목표비중을 추가로 부여하지 않습니다. 채권 ETF를 별도 등록한 금액은 채권·현금성 수동 평가액에 중복 입력하지 마세요.
- ETF 비교 화면의 기준 ETF 및 추천 순위는 보유목록과 별개이며 새 등록으로 자동 변경하지 않습니다.

테스트는 합성 잔고와 모의 저장소를 사용합니다. 실제 연금 보유파일에 테스트 거래를 등록하지 않습니다.
