# HY 전 시장 선행 탐지 v1 (관찰 전용)

## 목적과 범위
기존 HY 5-of-7, A/B 관찰, KIS 시세, 카카오 알림, 사용자 보유/저장 파일을 **변경하지 않는다**.
새 지표는 신뢰할 수 있는 *확정 일봉*의 가격·거래량 기술적 징후를 선별하는 연구 도구다.
뉴스 전 수익을 예측하거나 수익을 보장하지 않는다.

## 데이터
기존 일일 Naver 전 시장 검색 과정의 100개 일봉을 재사용하며, KOSPI/KOSDAQ 지수의
동일 기준일 데이터를 별도로 두 번 조회한다. 신규 API 인증 키나 주문 API는 사용하지 않는다.
지수 자료가 누락되면 초기 탐지는 **평가 보류**이며 다른 출처로 조용히 대체하지 않는다.
정규장 중 진행 중인 일봉은 대상이 아니다. 거래 정지/권리변동 의심 종목도 제외한다.

## 신호
- 최근 5거래일 내 20일선 아래→위 회복
- 최근 5거래일 내 RSI(14) 50 상향돌파 (Wilder 평활)
- MACD(EMA12−EMA26) 히스토그램 3거래일 연속 증가
- 직전 20거래일 평균 대비 당일 거래량 1.5배 이상
- 동일 기준일 KOSPI/KOSDAQ 지수 대비 최근 5거래일 초과수익 양수

후보는 5개 중 3개 이상, RSI 돌파 또는 MACD 개선, 거래량 1.2배 이상,
가격이 20일선 위 0~10%, 최근 5일 상승률 18% 이하, 가격 1,000원 이상,
20일 평균 거래대금 약 20억원 이상을 모두 만족한다. **기준값은 검증 전 가설**이다.
RSI/MACD는 수집 가능한 일봉으로 자체 계산하며 미래 봉을 사용하지 않는다.

## 표시 및 상태
일일 검색 상태의 `early_detector` 필드에 상위 30개만 별도 저장한다.
화면에서 '전 시장 선행 탐지(시험)'으로 확인하며 실시간 매수 신호로 혼동하지 않는다.
완료되지 않은 검색이나 API 오류는 '평가 보류'로 표시한다.
자동 알림·실제 매매는 추가하지 않는다.

## 남은 검증
1. 3~5년 생존편향 없는 역사적 전 종목 데이터로 워크포워드 백테스트
2. 수수료·세금·슬리피지 반영 및 거래대금/호가 충격 분석
3. 발견 후 5·10·20거래일 수익률, 승률, 손익비, MDD, 거짓신호 비교
4. 업종분류 누락 개선 및 기관·외국인 수급 적시성 검증
5. KIS 인증/현재가 운영 상태 별도 확인 (코드만으로 비밀키 설정/접속 성공 검증 불가)
