# HY 미너비니 8조건 (독립 연구 기능)

## 목적과 격리
- 기존 5-of-7 필수 4개 + 보조 3개 중 1개 신호는 수정하지 않는다.
- 기존 전 시장 선행 탐지의 RSI·MACD·5신호와 개인관찰 A/B 목록도 수정하지 않는다.
- 미너비니 결과는 매수 추천, 보유 종목 변경, 카카오 알림, 주문으로 이어지지 않는다.
- 기존 각 화면에서 접이식 **미너비니 8조건 평가**를 열고 특정 종목 또는 현재 관찰목록 전체를 수동 평가한다.
- 최초 화면 진입 자체만으로 Naver 일봉을 20개씩 다운로드하지 않는다.

## 8조건
1. 종가가 150일, 200일 SMA 위
2. 150일 SMA가 200일 SMA 위
3. 200일 SMA가 21거래일 전보다 상승
4. 50일 SMA가 150일, 200일 SMA 위
5. 종가가 50일 SMA 위
6. 종가가 최근 252거래일 **저가(Low)** 대비 최소 +30%
7. 종가가 최근 252거래일 **고가(High)** 의 75% 이상
8. **전체시장 HY 상대강도 백분위**가 70 이상

8번은 RSI도, IBD 공식 RS Rating도 아니다. HY는 3/6/9/12개월 수익률을 40/20/20/20% 비율로 평균해 같은 기준일의 종목들끼리 서열화한다.

## 데이터 품질과 자료 보류
- 253개 이상 확정 일봉, 마지막 거래일=스냅샷 기준일, 날짜 단조증가·중복 없음, OHLC 양수·유효 범위 필수.
- 약한 가격 검증에 걸렸거나 과거 일봉이 부족하면 미통과가 아니라 **평가 보류**.
- 전체시장 동시기준 RS는 최소 1,000종목, 종목목록 대비 정상 평가 80% 이상이 있어야 산출한다. 단순한 20개 개인관찰목록의 RS 순위를 전체시장 RS로 오인하지 않는다.
- 전체시장 스캔 완료 자료가 없으면 8번은 **보류**, 7/8을 8/8로 표시하지 않는다.
- Naver 원시 일봉은 기업행사 시 수정주가가 적절하지 않을 수 있다.

## 실행
```bash
python -m unittest discover -s tests -p 'test_minervini_trend.py' -v
python scripts/scan_minervini.py --asof 2026-11-20 --workers 3 --output /tmp/minervini_market_scan.json
```

위 명령은 **읽기 전용**으로 로컬 JSON만 생성한다. 기존 HY `monitor-state` 브랜치나 카카오 알림 파일은 수정하지 않는다. 품질 검증 후 신규 `data/minervini_market_scan.json` 파일만 별도 게시하면 화면에서 RS를 사용할 수 있다.

### 아직 검증되지 않은 것
- 1년 또는 3~5년간 **서로 다른 8/8 통과 종목의 누적 개수**는 전체 기간의 날짜별 시장 구성을 복원해야 하므로 현재 단일일 스캔으로 계산하지 않는다.
- 당시의 장중 거래량·가격·알림 관측 상태가 없으면 과거 5-of-7 실시간 매수신호와의 교집합을 정확히 재현할 수 없다.
- 스캐너의 대상 종목목록은 현재 시점에 조회하므로 과거 상장폐지·합병 종목의 **생존편향**이 발생할 수 있다.
- 실거래 전 시장 데이터 품질, 시세 출처, 정정주가, 체결 지연과 거래 비용을 확인해야 한다.
