# 주도업종 우선 후보 화면

상승시점 관찰 → 단기/중기 프로젝트의 기본 목록은 `주도업종 후보`입니다.
이 문서의 후보 범위는 이전의 저장 종목 우선 범위 설명을 대체합니다.

1. 기존 10개 업종 그래프와 동일한 확정 종가의 **20일 KOSPI 대비 강도 1위**부터 선택합니다.
   양수 공동 1위면 동률 업종만 포함합니다. 3일 유지 전에는 `유지 확인 중`입니다.
   전체 10개 업종 자료 누락, 서로 다른 날짜, 1위도 시장 하회 시 보류하며 2위로 대체하지 않습니다.
   중기도 같은 업종을 사용하되 기존 20·60일 종목 조건과 실적·공시 요건은 유지합니다.
2. `SECTORS` 대표 종목과 `BUSINESSES`의 검토된 비교업종 매핑에서 해당 업종 코드를 찾습니다.
   저장 20개/208개에 제한하지 않습니다. 공식 업종 전체 또는 전 시장 검색이라는 뜻은 아닙니다.
   복합기업·테마만 있는 미지정 종목은 제외하며 현재 2차전지 분류 대상은 4개입니다.
3. 기존 일일 검색기의 읽기 전용 Naver 상장목록·거래상태·일봉을 재사용합니다.
   기존 서버 저장자료에 없는 LG에너지솔루션/삼성SDI 등도 직접 조회합니다.
   기준일별 1시간 캐시, 전체 상장목록은 공유 캐시, 일봉은 해당 업종만 최대 4개 동시 요청입니다.
   수신 실패, 거래정지, 거래상태 미확인, 최신 종가/거래량/65봉 부족, 권리변동 의심은 제외·표시합니다.
4. 기존 단기/중기 보통주·유동성·가격 추세 조건을 적용하고, 해당 업종 대비 수익률로 정렬한 뒤 최대 20개를 표시합니다.
   단기는 20일 → 60일 → 거래대금, 중기는 60일 → 20일 → 거래대금 순입니다. 숫자를 채우지 않습니다.
5. 카드 수·종목명·표·상세 차트는 같은 후보 범위입니다. 실제 업종 비교와 진입 평가는 기존 KIS 일봉/현재가,
   동일 61거래일 검증을 유지합니다. 자료 제공처 차이/기준일 불일치는 기존 방식대로 보류합니다.

`기존 저장 관찰종목`은 기록·보유 관리를 위한 별도 화면입니다. 선택 시 이전 저장목록과 보유 평가를 볼 수 있습니다.
`다음 주도업종 관찰`은 1위가 아닌 양수 강도 업종의 별도 접힌 표이며 기본 후보에 섞지 않습니다.
미리보기·가격 타이머·업종 변경은 저장하지 않습니다. 관찰 추가/종료/체결/계획 저장은 기존 명시적 버튼으로만 실행합니다.
최대 20개 저장 제한과 실제 보유 기록이 있는 종목의 종료 금지, 단기·중기 원장 분리도 유지합니다.

검증 전 관찰 규칙입니다. 주도업종·후보 포함·3단계 충족은 매수 권고, 수익 보장, 전 시장의 최강 종목이라는 뜻이 아닙니다.
