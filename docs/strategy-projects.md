# 단기·중기 프로젝트

상승시점관찰 → 투자 프로젝트 선택에서 단기, 중기, 기존 개인관찰을 전환합니다.
기존 개인관찰 20개와 원본 저장목록은 변경하지 않습니다. 프로젝트를 처음 열면
완료된 일일 자료로 후보를 미리 보여주며, `현재 후보 최대 20개로 관찰 시작`을
누른 경우에만 해당 프로젝트에 저장합니다. 가격 갱신으로 종목을 교체하지 않습니다.

- 단기: 10·20일 상승과 20일 시장 초과 상승·유동성 중심 후보. 장중 잠정 돌파/눌림 평가.
- 중기: 20·60일 시장 초과 상승과 정배열 중심 후보. 확정 종가로만 돌파/눌림 평가.
- 수렴은 참고이고 실적·공시 확인은 직접 입력합니다. 기업 실적 자동분석은 없습니다.
- 4/4는 검토용 기술 필터이지 매수 권고·주문·성과가 검증된 전략이 아닙니다.
- 후보는 기존 저장 종목 범위이며 업종 전체 대표주 발굴이나 업종 내 순위가 아닙니다.
  고정 대표 3종목 업종지표와 사업 분류는 참고이며 미확인은 추정하지 않습니다.
- 장중 가격은 10초 조회 요청, 통신 지연 가능. 휴일에는 최근 확인 거래일 종가를 표시합니다.
- 거래 기록은 실제 증권사 체결을 사용자가 입력하며 자동 주문·계좌동기화는 없습니다.
  매수비용 포함 평균원가·부분매도·입력한 매도비용을 반영합니다. 기업행사는 자동 조정하지 않습니다.
- 잘못된 체결은 무효 표시하고 원본과 사유를 보관합니다. 이후 매도에 필요한 매수는
  먼저 무효화할 수 없습니다. 해당 매도를 정정한 뒤 순서대로 수정합니다.
- 손절 계획과 기술적 참고 손절은 별개입니다. 위험 수량 계산은 배정금액 기준 예시이며
  잔여현금·기존 위험·비용·갭 하락을 포함하지 않습니다.

저장: 기존 GitHub `monitor-state` 브랜치의 `data/strategy_projects.json` 한 문서 안에서
short/medium 목록·계획·거래·배정금액을 분리합니다. 열람·타이머는 쓰기를 하지 않습니다.
저장 시 원격 SHA를 다시 비교하고 충돌 시 중단합니다. 기존 계좌/연금 기록은 복사하지 않습니다.
저장 권한과 노출 범위는 기존 저장소 접근 설정을 따릅니다.

검증: 규칙/원장/동시수정 단위 테스트와 Streamlit 가상 UI 테스트. 가상 fixture는
실제 시세·원격 저장·주문을 사용하지 않습니다. 과거 성과 백테스트는 포함하지 않습니다.
